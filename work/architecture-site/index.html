建筑作品集

我的建筑作品集网站：十二个项目拼成一面照片墙，中英文双语，国内外都能打开。

技术
Astro, Lenis, Puppeteer
年份
2026

这是我的建筑作品集网站，收录 2014 到 2026 年的十二个项目。首页把所有项目的照片拼成一面倾斜的菱形照片墙，往下滚动时墙面放平，变成项目索引；项目可以按实践和学术筛选，在列表和网格之间切换。

整站有中英文两个版本，所有页面和项目说明都有中文翻译。字体随网站一起打包，中文使用系统字体，不依赖 Google Fonts，所以在中国大陆也能正常加载。网站同时部署在 Vercel 和 GitHub Pages 两个地址，源文件和原图不公开。

同一套内容还能用 Chrome 打印成 A3 横版 PDF，分国际版和国内版，分别链接到对应的网站地址。

右边可以直接浏览这个网站。
