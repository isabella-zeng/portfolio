Architecture portfolio

My architecture portfolio site: twelve projects tiled into one photo wall, in English and Chinese, reachable inside and outside China.

Stack
Astro, Lenis, Puppeteer
Year
2026

This is my architecture portfolio site, with twelve projects from 2014 to 2026. The home page tiles photos from every project into a tilted diamond wall that flattens into a project index as you scroll; projects can be filtered by practice or academic work and viewed as a list or a grid.

The whole site comes in English and Chinese, with every page and project description translated. Fonts ship with the site and Chinese uses system fonts rather than Google Fonts, so it loads properly in mainland China. It is deployed to both Vercel and GitHub Pages, and the source files and original images stay private.

The same content also prints from Chrome as an A3 landscape PDF, in an international edition and a China edition that each link to the matching site.
